Aptible is a Platform as a Service (PaaS) built for teams that have to prove security and compliance, not just ship. It deploys web apps, managed databases (PostgreSQL, MySQL, Redis, Elasticsearch, InfluxDB, RabbitMQ, SFTP) and AI workloads onto isolated, dedicated AWS infrastructure with encryption, host hardening, DDoS protection, managed host intrusion detection and vulnerability scanning enforced by default. Aptible ships HIPAA Business Associate Agreements, HITRUST R2 inheritance, SOC 2, PCI DSS and PIPEDA support alongside a Security & Compliance Dashboard, and more recently an LLM Gateway (400+ models behind one compliant API, with audit logging, spend limits and model access policies) and an MCP Gateway that governs how teams and agents reach MCP servers. The platform is driven by a public HAL+JSON REST API at api.aptible.com, an auth service at auth.aptible.com, a Ruby CLI, a Terraform provider, and generated Go/Ruby/Python client libraries.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Aptible: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
